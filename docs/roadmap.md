# FormulaLab Roadmap

FormulaLab should remain a lightweight engineering-note plugin. The project direction is to support fast, visual reasoning inside Obsidian rather than replace dedicated analysis software.

## Near-term

- Add more robust validation messages for malformed YAML blocks
- Add example notes for propulsion and fluid-mechanics calculations
- Add screenshot or GIF documentation for the main README
- Prepare release zip workflow for `manifest.json`, `main.js`, and `styles.css`

## Engineering Note Features

- Reynolds number calculator examples
- Weber number calculator examples
- Momentum flux ratio examples
- Pitot velocity documentation for high-pressure gas test notes

## Medium-term

- Data overlay from small CSV snippets
- Parameter presets
- Multiple formula cards in one note
- Reduced Plotly bundle size

## Deliberately Out of Scope for Now

- Full symbolic algebra
- CFD post-processing
- Large dataset visualization
- 3D simulation plotting
- General-purpose notebook replacement
